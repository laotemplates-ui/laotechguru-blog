## ບົດນຳ

ຄົນເຮັດວຽກອອຟຟິດສ່ວນຫຼາຍໃຊ້ Excel ທຸກມື້ ແຕ່ຫຼາຍຄົນຍັງໃຊ້ເມົາສ໌ຄລິກເມນູໄປມາ ເສຍເວລາໂດຍບໍ່ຈຳເປັນ — ບົດຄວາມນີ້ຈະລວມ 10 Shortcut ພື້ນຖານທີ່ຊ່ວຍໃຫ້ເຮັດວຽກໄວຂຶ້ນຫຼາຍເທົ່າ, ໃຊ້ໄດ້ທັງ Windows ແລະ Mac (ວົງເລັບ Mac ຈະລະບຸໄວ້ແຍກ)

## 1. Ctrl + Z / Ctrl + Y — Undo / Redo

ຄີລັດພື້ນຖານທີ່ສຸດ — `Ctrl + Z` ຍົກເລີກການກະທຳຫຼ້າສຸດ, `Ctrl + Y` ເຮັດຄືນສິ່ງທີ່ຍົກເລີກໄປ (Mac: `Cmd + Z` / `Cmd + Shift + Z`)

## 2. Ctrl + Arrow Keys — ໂດດໄປຫາຂອບຂອງຂໍ້ມູນ

ກົດ `Ctrl` ພ້ອມລູກສອນ (↑↓←→) ຈະໂດດຈາກ cell ປັດຈຸບັນໄປຫາ cell ສຸດທ້າຍທີ່ມີຂໍ້ມູນຕິດກັນໃນທິດທາງນັ້ນ — ໄວກວ່າການເລື່ອນລົງເບິ່ງທີລະແຖວຫຼາຍ ໂດຍສະເພາະ table ທີ່ມີຫຼາຍພັນແຖວ

## 3. Ctrl + Shift + Arrow — ເລືອກຂໍ້ມູນທັງແຖວ/ຖັນທັນທີ

ຄືກັນກັບຂໍ້ 2 ແຕ່ເພີ່ມ `Shift` ເຂົ້າ — ຈະ**ເລືອກ** ຂໍ້ມູນທັງໝົດແທນ (ໂດຍບໍ່ຕ້ອງລາກເມົາສ໌) ເໝາະສຳລັບການ copy ຖັນ/ແຖວທີ່ຍາວຫຼາຍໆພັນແຖວ

## 4. Ctrl + T — ແປງເປັນ Table ອັດຕະໂນມັດ

ເລືອກຂໍ້ມູນ ແລ້ວກົດ `Ctrl + T` — Excel ຈະແປງເປັນ Table ອັດຕະໂນມັດ (ໃສ່ ຟິວເຕີ, ໂຕນສີສະຫຼັບແຖວ, ແລະ ຂະຫຍາຍສູດອັດຕະໂນມັດເມື່ອເພີ່ມແຖວໃໝ່) ດີກວ່າການຈັດການ range ທຳມະດາຫຼາຍ

## 5. F4 — ເຮັດຄຳສັ່ງລ່າສຸດຊ້ຳ (Repeat)

ຫຼັງຈາກເຮັດຫຍັງອັນໜຶ່ງແລ້ວ (ເຊັ່ນ ໃສ່ສີພື້ນຫຼັງ cell, ລຶບແຖວ) ກົດ `F4` ຈະເຮັດຄຳສັ່ງດຽວກັນນັ້ນຊ້ຳກັບ cell/ບ່ອນອື່ນທັນທີ ໂດຍບໍ່ຕ້ອງກັບໄປຫາເມນູໃໝ່ (Mac: `Cmd + Y`)

## 6. Alt + = — ບວກເລກລວມ (SUM) ອັດຕະໂນມັດ

ເລືອກຖັນ/ແຖວຕົວເລກ ແລ້ວກົດ `Alt + =` — Excel ຈະໃສ່ສູດ `SUM()` ໃຫ້ອັດຕະໂນມັດ ພ້ອມເລືອກຂອບເຂດຂໍ້ມູນທີ່ຖືກຕ້ອງໃຫ້ ບໍ່ຕ້ອງພິມສູດເອງ (Mac: `Cmd + Shift + T` ໃນບາງເວີຊັນ, ຫຼືໃຊ້ Function ปุ่ม Σ ແທນ)

## 7. Ctrl + ; — ໃສ່ວັນທີປັດຈຸບັນທັນທີ

ກົດ `Ctrl + ;` ຈະໃສ່ວັນທີຂອງມື້ນີ້ໃນ cell ທັນທີ (ຄ່າຄົງທີ່ ບໍ່ອັບເດດຕາມ) — ໃຊ້ໄດ້ດີສຳລັບໃສ່ວັນທີສ້າງເອກະສານ ຫຼືວັນທີບັນທຶກຂໍ້ມູນ

## 8. Ctrl + 1 — ເປີດ Format Cells ໄວທີ່ສຸດ

ແທນທີ່ຈະຄລິກ ຂວາ → Format Cells → ໃຊ້ `Ctrl + 1` ໄດ້ທັນທີ — ເປີດໜ້າຕ່າງຈັດຮູບແບບ cell (ຕົວເລກ, ວັນທີ, ຂອບ, ສີພື້ນຫຼັງ) ໄວກວ່າຫຼາຍ

## 9. Ctrl + Page Up / Page Down — ສະຫຼັບລະຫວ່າງ Sheet

ຖ້າ workbook ມີຫຼາຍ sheet, `Ctrl + Page Down` ໄປ sheet ຖັດໄປ, `Ctrl + Page Up` ກັບ sheet ກ່ອນໜ້າ — ໄວກວ່າການຄລິກ tab ດ້ານລຸ່ມທຸກຄັ້ງ

## 10. F2 — ແກ້ໄຂເນື້ອຫາໃນ Cell ໂດຍກົງ

ແທນທີ່ຈະດັບເບີ້ນຄລິກ cell ເພື່ອແກ້ໄຂ, ກົດ `F2` ຈະເຂົ້າໂໝດແກ້ໄຂ cell ທີ່ເລືອກໄວ້ທັນທີ (커서 ໄປຢູ່ທ້າຍຂໍ້ຄວາມ) ສະດວກກວ່າສຳລັບຄົນທີ່ໃຊ້ keyboard ເປັນຫຼັກ

## ສະຫຼຸບ

ຄີລັດ 10 ອັນນີ້ ຄອບຄຸມການໃຊ້ງານ Excel ພື້ນຖານທີ່ຄົນອອຟຟິດເຮັດຊ້ຳໆທຸກມື້ — ຖ້າຈື່ໄດ້ພຽງ 3-4 ອັນ (Ctrl+T, Alt+=, F4, Ctrl+1) ກໍ່ຈະຮູ້ສຶກໄດ້ຄວາມແຕກຕ່າງແລ້ວ ຄ່ອຍໆຝຶກໃຊ້ເລື້ອຍໆ ຈົນກາຍເປັນນິໄສ ຈະຊ່ວຍປະຢັດເວລາເຮັດວຽກໄດ້ຫຼາຍໃນໄລຍະຍາວ.
