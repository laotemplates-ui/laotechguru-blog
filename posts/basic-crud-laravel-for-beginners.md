ຖ້າໃຜທີ່ກຳລັງເລີ່ມຕົ້ນຮຽນຂຽນເວັບໄຊ, ຄຳວ່າ "CRUD" ຖືເປັນສິ່ງທີ່ຫຼີກລ່ຽງບໍ່ໄດ້ເລີຍ ເພາະມັນຄືຫົວໃຈຫຼັກຂອງທຸກໆແອັບພລິເຄຊັນ (Create ສ້າງ, Read ອ່ານ, Update ແກ້ໄຂ, Delete ລຶບ). ມື້ນີ້ເຮົາຈະມາຮຽນຮູ້ວິທີການສ້າງລະບົບ CRUD ພື້ນຖານໂດຍໃຊ້ Laravel ເຊິ່ງເປັນ PHP Framework ທີ່ຊ່ວຍໃຫ້ເຮົາຂຽນໂປຣແກຣມໄດ້ງ່າຍ ແລະ ໄວຂຶ້ນຫຼາຍ.

## 1. ກຽມຄວາມພ້ອມ ແລະ ສ້າງໂປຣເຈັກໃໝ່

ກ່ອນອື່ນໝົດ ໃຫ້ເປີດ Terminal ຂຶ້ນມາ ແລ້ວພິມຄຳສັ່ງນີ້ເພື່ອສ້າງໂປຣເຈັກ Laravel ໃໝ່:

```bash
composer create-project laravel/laravel my-crud-app
```

ຄຳສັ່ງນີ້ຈະບອກໃຫ້ Composer (ຕົວຈັດການ package ຂອງ PHP) ໄປດາວໂຫຼດ ແລະ ຕິດຕັ້ງໂຄງສ້າງໄຟລ໌ທັງໝົດຂອງ Laravel ມາໄວ້ໃນໂຟລເດີທີ່ຊື່ວ່າ `my-crud-app` ເພື່ອໃຫ້ເຮົາພ້ອມເລີ່ມເຮັດວຽກໄດ້ທັນທີໂດຍບໍ່ຕ້ອງເລີ່ມຈາກສູນ.

## 2. ຕັ້ງຄ່າການເຊື່ອມຕໍ່ຖານຂໍ້ມູນ (Database)

ຫຼັງຈາກສ້າງໂປຣເຈັກແລ້ວ, ໃຫ້ເປີດໂຟລເດີນັ້ນຂຶ້ນມາໃນ Code Editor (ເຊັ່ນ VS Code) ແລ້ວຊອກຫາໄຟລ໌ຊື່ວ່າ `.env`. ໃຫ້ປ່ຽນຄ່າໃນສ່ວນຂອງ Database ໃຫ້ກົງກັບຖານຂໍ້ມູນຂອງທ່ານ:

```ini
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_crud
DB_USERNAME=root
DB_PASSWORD=
```

ທີ່ເຮົາຕ້ອງຕັ້ງຄ່າໃນໄຟລ໌ `.env` ກໍ່ເພື່ອໃຫ້ Laravel ຮູ້ວ່າຈະຕ້ອງເຊື່ອມຕໍ່ກັບຖານຂໍ້ມູນຊື່ຫຍັງ (ໃນຕົວຢ່າງນີ້ຄື `laravel_crud`), ພ້ອມທັງລະບຸ Username ແລະ Password ເພື່ອໃຫ້ລະບົບສາມາດເຂົ້າໄປດຶງ ຫຼື ບັນທຶກຂໍ້ມູນໄດ້ຢ່າງຖືກຕ້ອງ.

## 3. ສ້າງ Model ແລະ Migration ສຳລັບເກັບຂໍ້ມູນ

ສົມມຸດວ່າເຮົາຢາກເຮັດລະບົບເກັບຂໍ້ມູນ "ສິນຄ້າ" (Product). ເຮົາສາມາດສ້າງ Model ແລະ ຕາຕະລາງໃນຖານຂໍ້ມູນໄປພ້ອມໆກັນດ້ວຍຄຳສັ່ງດຽວ:

```bash
php artisan make:model Product -m
```

ຄຳສັ່ງ `make:model` ພ້ອມກັບການຕື່ມ `-m` ຢູ່ທາງທ້າຍ ແມ່ນການສັ່ງໃຫ້ Laravel ສ້າງທັງ Model (ສຳລັບຈັດການຂໍ້ມູນໃນຝັ່ງ Code) ແລະ Migration (ສຳລັບສ້າງຕາຕະລາງໃນຖານຂໍ້ມູນ) ໄປພ້ອມກັນ, ເຊິ່ງຊ່ວຍປະຢັດເວລາຂອງເຮົາໄດ້ຫຼາຍ.

ຈາກນັ້ນໃຫ້ເຂົ້າໄປທີ່ໄຟລ໌ Migration ທີ່ຫາກໍ່ຖືກສ້າງຂຶ້ນໃນໂຟລເດີ `database/migrations` ແລ້ວເພີ່ມຖັນ (column) ທີ່ຕ້ອງການ ເຊັ່ນ: ຊື່ສິນຄ້າ ແລະ ລາຄາ.

```php
public function up()
{
    Schema::create('products', function (Blueprint $table) {
        $table->id();
        $table->string('name');
        $table->decimal('price', 8, 2);
        $table->timestamps();
    });
}
```

ໂຄດສຳລັບ Migration ນີ້ຄືການອະທິບາຍໂຄງສ້າງຂອງຕາຕະລາງໃຫ້ລະບົບຮູ້ວ່າ ຖັນ `name` ຈະເກັບຂໍ້ມູນເປັນຕົວໜັງສື (string) ແລະ ຖັນ `price` ຈະເກັບຂໍ້ມູນເປັນຕົວເລກທົດສະນິຍົມ.

ຫຼັງຈາກຂຽນສຳເລັດແລ້ວ ຢ່າລືມລັນຄຳສັ່ງ `php artisan migrate` ເພື່ອສ້າງຕາຕະລາງໃນຖານຂໍ້ມູນແທ້ໆ.

## 4. ສ້າງ Controller ເພື່ອຄວບຄຸມການເຮັດວຽກ

Controller ຈະເປັນຕົວເຊື່ອມລະຫວ່າງໜ້າເວັບ (View) ແລະ ຖານຂໍ້ມູນ (Model).

```bash
php artisan make:controller ProductController --resource
```

ການໃສ່ຄຳວ່າ `--resource` ເຂົ້າໄປນຳ ຈະເຮັດໃຫ້ Laravel ສ້າງ Controller ທີ່ກຽມຟັງຊັນສຳລັບເຮັດ CRUD ມາໃຫ້ເຮົາແບບຄົບຖ້ວນ (ເຊັ່ນ: index ສຳລັບສະແດງລາຍການ, create ສຳລັບໜ້າສ້າງໃໝ່, update ສຳລັບແກ້ໄຂ, destroy ສຳລັບລຶບ). ເຮົາພຽງແຕ່ເຂົ້າໄປຂຽນໂຄດໃສ່ທາງໃນແຕ່ລະຟັງຊັນກໍ່ພໍ.

## 5. ສ້າງ Routes

ສຸດທ້າຍ, ເຮົາຕ້ອງບອກໃຫ້ລະບົບຮູ້ວ່າ ເມື່ອມີຄົນພິມ URL ເຂົ້າມາ ຈະໃຫ້ໄປເອີ້ນໃຊ້ Controller ຕົວໃດ. ໃຫ້ເປີດໄຟລ໌ `routes/web.php` ແລ້ວເພີ່ມໂຄດນີ້ລົງໄປ:

```php
use App\Http\Controllers\ProductController;

Route::resource('products', ProductController::class);
```

ດ້ວຍໂຄດພຽງແຖວດຽວນີ້, Laravel ຈະທຳການສ້າງ URL ສຳລັບລະບົບ CRUD ຂອງສິນຄ້າໃຫ້ເຮົາອັດຕະໂນມັດທັງໝົດ, ເຊິ່ງເຮັດໃຫ້ການຈັດການ Routing ງ່າຍ ແລະ ເປັນລະບຽບຫຼາຍ.

ການສ້າງ CRUD ດ້ວຍ Laravel ອາດເບິ່ງຄືມີຫຼາຍຂັ້ນຕອນໃນຕອນທຳອິດ, ແຕ່ຖ້າເຮົາເຂົ້າໃຈຫຼັກການແລ້ວ ມັນຈະຊ່ວຍໃຫ້ເຮົາພັດທະນາລະບົບໄດ້ໄວຂຶ້ນຫຼາຍ. ສຳລັບການສະແດງຜົນໜ້າຕາເວັບ (Views) ທ່ານສາມາດສ້າງໄຟລ໌ `.blade.php` ເພື່ອເຮັດຟອມຮັບຂໍ້ມູນຕ່າງໆໄດ້ເລີຍ. ລອງນຳໄປຝຶກຂຽນກັນເບິ່ງເດີ້!
