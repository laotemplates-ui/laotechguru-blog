ສະບາຍດີເພື່ອນໆຊາວ LaoTechGuru ທຸກຄົນ! ຈາກຮູບພາບທີ່ເຫັນນີ້ ແມ່ນບັນຍາກາດການເຮັດວຽກທີ່ໜ້ານັ່ງຫຼາຍ, ແຕ່ສິ່ງທີ່ໜ້າສົນໃຈກໍຄື ເຮົາຈະເຫັນວ່າໜ້າຈໍທີ່ໃຊ້ສະແດງຜົນໂຄດນັ້ນ ມີທັງຈໍຄອມພິວເຕີຕັ້ງໂຕະ ແລະ ຈໍຂອງແທັບເລັດ (Tablet) ຕັ້ງຢູ່ຄູ່ກັນ. ຫຼາຍຄົນທີ່ກຳລັງຢາກກ້າວເຂົ້າສູ່ວົງການໄອທີ ອາດຈະເຄີຍມີຄຳຖາມໃນໃຈວ່າ: "ຖ້າເຮົາຍັງບໍ່ທັນມີງົບຊື້ຄອມພິວເຕີ ຫຼື ໂນດບຸກ, ເຮົາສາມາດໃຊ້ແທັບເລັດ ຫຼື iPad ທີ່ໃຊ້ຮຽນອອນລາຍຢູ່ ມາຝຶກຂຽນໂປຣແກຣມໄດ້ບໍ່?" ມື້ນີ້ເຮົາມາຫາຄຳຕອບນຳກັນເລີຍ!

## Tablet ສາມາດໃຊ້ຂຽນໂປຣແກຣມໄດ້ແທ້ບໍ່?

ຂໍຕອບຊັດເຈນຕົງນີ້ເລີຍວ່າ **"ໄດ້ແນ່ນອນ!"** ສຳລັບຜູ້ທີ່ເລີ່ມຕົ້ນຮຽນຂຽນໂປຣແກຣມໃໝ່ໆ, ບໍ່ວ່າຈະເປັນການຮຽນສ້າງເວັບໄຊດ້ວຍ HTML/CSS ຫຼື ຮຽນພາສາພື້ນຖານເຊັ່ນ Python ແລະ JavaScript ມັນບໍ່ໄດ້ກິນສະເປັກເຄື່ອງໜັກເລີຍ. ແທັບເລັດລຸ້ນໃໝ່ໆໃນປັດຈຸບັນ ມີຄວາມແຮງພຽງພໍທີ່ຈະລັນ (Run) ໂຄດພື້ນຖານເຫຼົ່ານີ້ໄດ້ສະບາຍໆ ໂດຍບໍ່ຈຳເປັນຕ້ອງໃຊ້ຄອມພິວເຕີລາຄາແພງກໍສາມາດຮຽນຮູ້ໄດ້.

## ຂໍ້ດີຂອງການຝຶກຂຽນໂຄດເທິງ Tablet

- **ພົກພາງ່າຍ:** ເຈົ້າສາມາດເອົາໄປນັ່ງຂຽນຢູ່ຮ້ານກາເຟ, ຫ້ອງສະໝຸດ, ຫຼື ແມ້ກະທັ່ງນັ່ງພິມຢູ່ເທິງຕຽງນອນກໍສະດວກສະບາຍ.
- **ແບັດເຕີຣີອຶດ:** ໂດຍທົ່ວໄປແລ້ວ Tablet ຈະໃຊ້ງານໄດ້ດົນກວ່າໂນດບຸກ ເຮັດໃຫ້ເຮົາສາມາດນັ່ງສຶກສາ ແລະ ຝຶກຂຽນໂຄດໄດ້ຫຼາຍຊົ່ວໂມງໂດຍບໍ່ຕ້ອງສຽບສາຍສາກ.
- **ປະຢັດງົບ:** ຖ້າເຮົາມີ Tablet ຢູ່ແລ້ວ ກໍສາມາດເລີ່ມຕົ້ນຮຽນໄດ້ທັນທີ ບໍ່ຕ້ອງລໍຖ້າເກັບເງິນຊື້ຄອມເຄື່ອງໃໝ່.

## ແອັບພລິເຄຊັນ ແລະ ເຄື່ອງມືທີ່ຄວນຮູ້ຈັກ

ການຂຽນໂຄດໃນ Tablet ຈະແຕກຕ່າງຈາກຄອມພິວເຕີໜ້ອຍໜຶ່ງ ຍ້ອນເຮົາບໍ່ສາມາດລົງໂປຣແກຣມໃຫຍ່ໆໄດ້. ແຕ່ໃນຍຸກນີ້ ເຮົາມີທາງເລືອກທີ່ສະດວກກວ່າ:

- **Web-based IDE (ຂຽນຜ່ານເວັບບຣາວເຊີ):** ເຮົາສາມາດໃຊ້ເວັບໄຊເຊັ່ນ Replit, CodePen, ຫຼື GitHub Codespaces ເຊິ່ງໃຫ້ເຮົາພິມໂຄດໃນເວັບ ແລະ ໃຫ້ເຊີບເວີ (Server) ຂອງເຂົາເຈົ້າປະມວນຜົນແທນ. ພຽງແຕ່ມີອິນເຕີເນັດ ກໍຂຽນໄດ້ທຸກພາສາ.
- **ແອັບສຳລັບຮຽນສະເພາະ:** ໃນ App Store ຫຼື Play Store ມີແອັບດີໆເຊັ່ນ Swift Playgrounds (ສຳລັບຄົນຢາກຂຽນແອັບ iPhone) ຫຼື Sololearn ທີ່ອອກແບບມາໃຫ້ຮຽນແລະພິມໂຄດໃນຈໍສຳຜັດໄດ້ງ່າຍ.

## ອຸປະກອນເສີມທີ່ "ຕ້ອງມີ" ຖ້າຢາກຮຽນຈິງຈັງ

ຖ້າເບິ່ງຈາກຮູບພາບ ເຮົາຈະເຫັນວ່າມີ **ຄີບອດ (Keyboard)** ວາງຢູ່. ນີ້ຄືສິ່ງສຳຄັນທີ່ສຸດ! ການພິມໂຄດທີ່ເຕັມໄປດ້ວຍສັນຍາລັກແປກໆ (ເຊັ່ນ: { } < > /) ດ້ວຍແປ້ນພິມໃນຈໍສຳຜັດ ແມ່ນເປັນຕາປວດຫົວ ແລະ ເຮັດໃຫ້ເຮົາທໍ້ໄດ້ງ່າຍ. ດັ່ງນັ້ນ, ການລົງທຶນຊື້ຄີບອດບູທູດ (Bluetooth Keyboard) ລາຄາບໍ່ແພງມາເຊື່ອມຕໍ່ກັບ Tablet ຈະຊ່ວຍໃຫ້ເຈົ້າພິມໂຄດໄດ້ໄວ ແລະ ມ່ວນຂຶ້ນຄືກັບໃຊ້ຄອມພິວເຕີແທ້ໆເລີຍ. ຖ້າມີເມົາສ໌ (Mouse) ນຳອີກ ກໍຍິ່ງສົມບູນແບບ!

## ຂໍ້ຈຳກັດທີ່ຕ້ອງຮູ້ໄວ້

ເຖິງຈະໃຊ້ເລີ່ມຕົ້ນໄດ້ດີ, ແຕ່ເມື່ອເຈົ້າຮຽນເກັ່ງຂຶ້ນ ແລະ ຢາກສ້າງໂປຣແກຣມທີ່ໃຫຍ່ຊັບຊ້ອນ, ຢາກພັດທະນາເກມ 3D ຫຼື ສ້າງແອັບທີ່ຕ້ອງໃຊ້ເຄື່ອງມືຫຼາຍໆຢ່າງພ້ອມກັນ. ມາຮອດຈຸດນັ້ນ, Tablet ອາດຈະບໍ່ຕອບໂຈດແລ້ວ ແລະ ເຈົ້າອາດຈະຕ້ອງໄດ້ຍັບຍ້າຍໄປໃຊ້ຄອມພິວເຕີ ຫຼື ໂນດບຸກແທນ. ແຕ່ສຳລັບການຮຽນຮູ້ພື້ນຖານໃນ 1-2 ປີທຳອິດ, Tablet ຖືວ່າເຫຼືອເຟືອ.

ສະຫຼຸບແລ້ວ, ຢ່າໃຫ້ຄຳວ່າ "ບໍ່ມີຄອມພິວເຕີ" ມາເປັນຂໍ້ອ້າງໃນການປິດກັ້ນການຮຽນຮູ້ຂອງເຮົາ. ໂລກຂອງການຂຽນໂປຣແກຣມເປີດກວ້າງສະເໝີສຳລັບຄົນທີ່ພ້ອມຈະລົງມືເຮັດ. ຖ້າເຈົ້າມີ Tablet ຢູ່ໃນມືແລ້ວ ລອງເຂົ້າເວັບທີ່ເຮົາແນະນຳ ແລ້ວເລີ່ມພິມໂຄດແຖວທຳອິດຂອງເຈົ້າໃນມື້ນີ້ເລີຍ! ແລ້ວພົບກັນໃໝ່ໃນບົດຄວາມໜ້າ ທີ່ LaoTechGuru ບ່ອນທີ່ຈະເຮັດໃຫ້ເລື່ອງໄອທີ ກາຍເປັນເລື່ອງງ່າຍໆສຳລັບທຸກຄົນ.
