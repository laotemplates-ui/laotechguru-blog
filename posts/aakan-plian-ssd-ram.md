## ບົດນຳ

ຄອມພິວເຕີທີ່ໃຊ້ໄປໄລຍະໜຶ່ງ ມັກຮູ້ສຶກຊ້າລົງ ຫຼາຍຄົນຄິດວ່າຕ້ອງຊື້ເຄື່ອງໃໝ່ທັນທີ — ແຕ່ຄວາມຈິງແລ້ວ ບັນຫາສ່ວນຫຼາຍແກ້ໄດ້ດ້ວຍການອັບເກຣດພຽງ 2 ຊິ້ນສ່ວນ: **SSD** ແລະ **RAM** ໂດຍບໍ່ຕ້ອງປ່ຽນທັງເຄື່ອງ, ປະຢັດເງິນໄດ້ຫຼາຍ. ນີ້ຄື 5 ອາການທີ່ບອກວ່າເຖິງເວລາອັບເກຣດແລ້ວ.

## 1. ເປີດເຄື່ອງ ຫຼື Windows ໃຊ້ເວລາດົນຫຼາຍ

ຖ້າຄອມພິວເຕີໃຊ້ HDD (jານດິສແບບເກົ່າ, ມີແຜ່ນໝູນ) ແທນ SSD — ການເປີດເຄື່ອງອາດໃຊ້ເວລາ 2-5 ນາທີ ຂະນະທີ່ SSD ໃຊ້ພຽງ 10-20 ວິນາທີ. ນີ້ຄືອາການທີ່ຊັດເຈນທີ່ສຸດວ່າຄວນປ່ຽນເປັນ SSD.

## 2. ເປີດຫຼາຍໂປຣແກຣມພ້ອມກັນແລ້ວເຄື່ອງກະຕຸກ

ຖ້າເປີດ browser ຫຼາຍ tab, Word, ແລະ ໂປຣແກຣມອື່ນພ້ອມກັນແລ້ວເຄື່ອງກະຕຸກ/ຄ້າງ — ອາດເປັນເພາະ RAM ບໍ່ພຽງພໍ. ກວດໄດ້ດ້ວຍການເປີດ **Task Manager** (Ctrl+Shift+Esc) ເບິ່ງ tab "Performance" ຖ້າ RAM ໃຊ້ເກີນ 80-90% ຕະຫຼອດເວລາ ຄວນເພີ່ມ RAM.

## 3. ໄຟລ໌ໂຫຼດຊ້າ, ຄັດລອກໄຟລ໌ໃຊ້ເວລາດົນ

ການເປີດໄຟລ໌ໃຫຍ່ (video, ຮູບ resolution ສູງ) ຫຼືຄັດລອກໄຟລ໌ຫຼາຍໆອັນ — ຖ້າໃຊ້ HDD ຈະຊ້າກວ່າ SSD ຫຼາຍເທົ່າ ເພາະ HDD ອ່ານ/ຂຽນຂໍ້ມູນຊ້າກວ່າ SSD ຫຼາຍຄັ້ງ (HDD ປົກກະຕິ ~100-150 MB/s ຂະນະທີ່ SSD ທົ່ວໄປ 500+ MB/s).

## 4. ຮູ້ສຶກວ່າ 8GB RAM ບໍ່ພຽງພໍອີກຕໍ່ໄປ

ຄອມພິວເຕີເກົ່າຫຼາຍໜ່ວຍມາພ້ອມ RAM 4-8GB — ຖ້າວຽກປັດຈຸບັນຕ້ອງເປີດ browser ຫຼາຍ tab, Zoom, ຫຼືໂປຣແກຣມອອກແບບ (Photoshop, Canva) ພ້ອມກັນ 8GB ອາດບໍ່ພຽງພໍອີກຕໍ່ໄປ — ແນະນຳ 16GB ຂຶ້ນໄປສຳລັບການໃຊ້ງານທົ່ວໄປໃນປັດຈຸບັນ.

## 5. ໄຟ Loading/Buffering ຂຶ້ນເລື້ອຍໆ ຕອນສະລັບໂປຣແກຣມ

ຖ້າສະລັບລະຫວ່າງໂປຣແກຣມແລ້ວຕ້ອງລໍ (ໄຟໝູນ ຫຼືໜ້າຈໍຄ້າງຊົ່ວຄາວ) — ນີ້ຄືສັນຍານວ່າ RAM ຫຼື SSD (ຫຼືທັງ 2 ຢ່າງ) ບໍ່ພຽງພໍກັບການໃຊ້ງານປັດຈຸບັນອີກຕໍ່ໄປ.

## ຄວນອັບເກຣດອັນໃດກ່ອນ?

ຖ້າຍັງໃຊ້ HDD ຢູ່ — **ອັບເກຣດ SSD ກ່ອນສະເໝີ** ເພາະໃຫ້ຄວາມແຕກຕ່າງທີ່ຮູ້ສຶກໄດ້ຫຼາຍທີ່ສຸດ (ເປີດເຄື່ອງໄວຂຶ້ນຫຼາຍເທົ່າ) ໃນລາຄາທີ່ບໍ່ແພງ, ຈາກນັ້ນຄ່ອຍພິຈາລະນາເພີ່ມ RAM ຖ້າຍັງຮູ້ສຶກຊ້າຢູ່ຫຼັງປ່ຽນ SSD ແລ້ວ.

## ສະຫຼຸບ

ຄອມພິວເຕີຊ້າ ບໍ່ຈຳເປັນຕ້ອງຊື້ເຄື່ອງໃໝ່ສະເໝີໄປ — ຖ້າມີອາການໃນ 5 ຂໍ້ຂ້າງເທິງ ລອງອັບເກຣດ SSD ຫຼື RAM ກ່ອນ ອາດໄດ້ຄອມພິວເຕີທີ່ໄວຂຶ້ນຫຼາຍໃນລາຄາທີ່ຖືກກວ່າຊື້ໃໝ່ຫຼາຍເທົ່າ.
